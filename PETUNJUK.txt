PERBAIKAN LIMA FILE E-WALLET TOKO SIAP ANTAR

File di dalam ZIP adalah lima file sumber E-Wallet yang sudah diperbaiki:
- ewallet-pelanggan.html
- ewallet-mitra-usaha.html
- ewallet-kurir.html
- ewallet-admin.html
- ewallet-superadmin.html

Perubahan:
1. Tombol Keluar menjalankan signOut Firebase, lalu mengarahkan pengguna ke index.html.
2. Setiap E-Wallet memiliki menu Halaman Utama menuju index.html.
3. Setiap E-Wallet memiliki navigasi lengkap sesuai role, dengan tautan ke halaman yang telah disepakati.
4. Navigasi dibuat responsif untuk HP dan desktop.

Cara pasang:
- Ekstrak ZIP.
- Unggah lima file HTML ke root repositori GitHub yang sama dengan index.html dan firebase-config.js.
- Timpa lima file E-Wallet lama.
- Pastikan nama file halaman tujuan tetap sama persis.
- Tes login, semua tautan navigasi, dan tombol Keluar.

Catatan: ZIP ini berisi lima file E-Wallet saja. File halaman lain dan index.html tidak diubah.
