PATCH GPS TOKO SIAP ANTAR

Ganti file lama berikut dengan file dari paket ini:
1. daftar-kurir.html
2. daftar-mitra-usaha.html

Perubahan:
- Menambahkan tombol ambil GPS dengan izin browser.
- Menampilkan koordinat dan perkiraan akurasi.
- Membuat link Google Maps otomatis dari koordinat.
- Menyimpan lat, lng, gpsLink, dan lokasi:{lat,lng} ke dokumen users/{uid}.
- Pendaftaran ditahan jika GPS belum berhasil diambil.
- Role/status verifikasi yang ada tetap dipertahankan.

Penting:
- Uji melalui HTTPS (misalnya hosting GitHub Pages/Vercel), karena geolocation biasanya tidak bekerja pada halaman HTTP biasa.
- Pengguna harus mengizinkan akses lokasi di browser dan mengaktifkan GPS perangkat.
- Ini memperbaiki penyimpanan koordinat awal saat registrasi. Untuk menentukan 3 kurir terdekat secara akurat saat pesanan masuk, sistem perlu membaca koordinat kurir aktif dan menghubungkan logika penawaran pesanan; file dashboard/penawaran belum diubah dalam patch ini.
